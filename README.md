# Seacoast Jazz Jams

Static, mobile-first page for Charlie Jennison's Portsmouth and Lee jams.

To update the schedule, edit `jams.js` and change the jam details or add a Press Room date to `pressRoom.dates`. The page automatically shows the next Press Room date and the next Monday Lee jam.

The Lee venue is shown as Mike's House in Lee, NH; contact Charlie for exact directions before going.
